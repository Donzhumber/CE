## Folder Organization

*   **`main/`**:
    *   `Bernal_H_COMP_ECON.tex`: Primary manuscript LaTeX source formatted with Springer Nature class (`sn-jnl.cls`).
    *   `references.bib` & `sn-mathphys-ay.bst`: Bibliography database and style.
    *   `Figures/`: Complete collection of 110 vector graphics (`.pdf` / `.png`).
*   **`appendix_A_micro/`**:
    *   Empirical calibration, Stata replication `.do` scripts, and microeconometric competing hazards estimation tables.
*   **`appendix_B_proofs/`**:
    *   Detailed formal mathematical proofs and interactive Lean 4 verification project.
*   **`Appendix_C_Streamlit/`**:
    *   Interactive simulation engine, PyTorch value approximation networks, and local launcher scripts.
*   **`additional_documents/`**:
    *   `cover_letter.tex`: Cover letter addressed to the Editorial Board of *Computational Economics* (Society for Computational Economics).
    *   `highlights.tex`: Key research contributions with computational and deep learning focus.
    *   `declaration_of_interest.tex`: Competing interest statement.
